# 📝 QuickNotes

A clean, modern, and responsive Notes App built with React and Tailwind CSS. Quickly create and delete notes with a smooth and intuitive UI.

---

## ✨ Features

- 📌 **Create Notes** — Add new notes instantly
- 🗑️ **Delete Notes** — Remove notes with a single click
- 📱 **Responsive UI** — Works seamlessly on all screen sizes
- ⚡ **Dynamic State Management** — Real-time updates using React state
- 🎨 **Clean & Modern Design** — Styled with Tailwind CSS

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React | UI Library |
| JavaScript | Core Language |
| Tailwind CSS | Styling |
| Vite | Build Tool |

---

## 🚀 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/quicknotes.git
   cd quicknotes
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. Open your browser and visit `http://localhost:5173`

---

## 📖 Usage

1. Type your note in the input field
2. Click **Add Note** to save it
3. Click the **delete** button on any note to remove it
4. Notes update instantly — no page reload needed
